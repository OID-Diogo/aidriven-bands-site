Platform features

Everything you need to manage
a music release

AI Driven Bands covers the full publishing workflow — from uploading media and writing captions to scheduling, reviewing, and confirming every post before it goes live.

Campaigns

Release campaign management

Group all content for a single release into one campaign. Manage teasers, release day posts, lyric videos and follow-up content together, across all connected platforms.

IG

Instagram — Feed, Reels, Stories

Upload videos to a connected YouTube channel via YouTube Data API v3. Configure title, description, tags, visibility and scheduled publish time from the dashboard.

TikTok integration

How TikTok publishing works

AI Driven Bands uses TikTok's official Content Posting API. Artists connect their own TikTok account through TikTok's OAuth authorization flow — the platform never stores TikTok credentials.

What the TikTok integration does

  • Connects the artist's TikTok account via official OAuth 2.0 authorization — the user logs in to TikTok directly, not through this platform
  • Stores only the resulting access token and refresh token, encrypted at rest with AES-256-GCM
  • Reads the account identifier required to address API calls
  • Reads post status after publication to confirm successful delivery

No follower data, DMs, analytics, or any other TikTok user information is accessed or stored.

1

Connect your TikTok account

From the band settings page, click "Connect TikTok". You are redirected to TikTok's official OAuth page to grant publishing permission. AI Driven Bands stores the resulting access token only.

2

Upload your video

Create a new campaign and upload your video file (up to 200 MB). The file is held on the server until the scheduled publish time, then deleted after successful publication.

3

Write caption and hashtags

Enter your caption manually or use the optional AI-assisted caption generator. Add hashtags and configure TikTok-specific settings for the post.

4

Declare commercial content

The TikTok publishing form includes an explicit commercial content declaration field. If the video contains branded content or paid promotion, the operator selects the appropriate disclosure option before confirming the post.

5

Set publish time

Choose to publish immediately or schedule for a future date and time. The scheduler runs every minute and dispatches due posts automatically.

6

Review and confirm

Before the post goes live, a review screen shows all details — video preview, caption, hashtags, commercial content flag, and scheduled time. The operator explicitly confirms. Nothing is published without confirmation.

Revoking access: Artists can revoke TikTok access at any time from their TikTok account under Settings & Privacy → Security → Authorized apps. Access can also be removed directly from the band settings page in AI Driven Bands.

Content tools

Content creation and management

✍️

AI-assisted captions

Generate caption suggestions for each post using AI. The operator reviews, edits and approves every generated caption before it is used. Nothing is published without human review.

🎬

Lyric video generator

Automatically generate lyric videos from uploaded audio and lyrics. Configurable fonts, colors and styles. Output is a video file ready for scheduling on any connected platform.

✂️

Teaser clips

Generate short teaser clips from a full video. The operator selects the segment and format; the platform renders the clip for use in Reels, TikTok, or Stories.

📁

Media management

Upload and organize media assets per release — images, audio files and videos. Files are stored securely until the scheduled post is published, then removed from the server.

Analytics

Performance tracking across platforms

After each post is published, the dashboard aggregates engagement data from connected platforms alongside streaming metrics for a complete view of release performance.

📈

Social engagement

Reach, impressions, plays, likes, comments and shares — pulled from the Meta Graph API, TikTok API and YouTube Analytics API after each post is live.

🎧

Spotify for Artists

Monthly listeners, stream counts, saves and playlist adds — read-only from the Spotify for Artists account linked to each band. Updated daily.

🎙️

Last.fm scrobbles

Total play counts from Last.fm for each registered artist, correlated with release dates and campaign activity to track organic listening growth.

📣

Meta Ads correlation

Connect Meta Ads data alongside organic post metrics to compare paid reach against streaming performance for a release campaign.
